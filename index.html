Retrieval-Augmented Generation Pipeline

From Aviation Documents to Intelligent Answers

A step-by-step trace of how AeroIntel transforms verified aviation documents into authoritative natural-language intelligence.

01

Aviation Knowledge

17 official source documents covering 9 aircraft models and 8 airlines loaded from authoritative records.

02

Document Processing

Raw texts parsed, validated, and normalized to extract structural metadata (aircraft, airline, manufacturer).

03

Text Chunking

Deterministic chunking creates 48 structured knowledge passages with stable hash IDs and metadata tagging.

04

Embedding Generation

Hugging Face sentence-transformers model maps each passage into dense 384-dimensional semantic vectors.

05

Pinecone Vector DB

Vectors indexed in Pinecone (aerointel-v2) with cosine metric and metadata filtering for fast search.

06

Semantic Retrieval

MCP toolset triggers filtered queries (search_aircraft, search_airline) returning relevant evidence passages.

07

LLM Response Gen

Google Gemini primary/fallback via ADK constructs grounded answers citing retrieved evidence strictly.

08

User Receives Answer

Synthesized, fact-checked response delivered via REST API and persisted in PostgreSQL session history.
